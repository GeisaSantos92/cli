# AGENTS.md

Instruções para agentes de IA que trabalham neste repositório.

## Contexto do projeto

Leia **[CLAUDE.md](CLAUDE.md)** — regras imutáveis, documentação de referência e estado

## Ao iniciar um projeto a partir deste starter

Siga o **[SETUP.md](SETUP.md)**: preencha a ficha do projeto (nome, logos, cores,
funcionalidades), rode `bin/rename.sh` para trocar os tokens do starter e só então
escreva código novo.
